# clip-hpc.github.io

**This repository is managed automatically. Do not change it.**

It holds the generated production build of the latest released CLIP website, served at <https://clip.science/> through this repository's GitHub Pages custom domain. The `release-pages.yml` deployment workflow in the CLIP website source repository replaces the whole `gh-pages` branch, including the `CNAME` file, on every release, so any manual change here is lost on the next deployment.

- Issues, pull requests, and discussions are disabled. Contact contact@clip.science with questions about CLIP. If you have an account, contact the HPC Servicedesk.
