# Documentation

Where to find step-by-step technical documentation for CLIP and CBE.

Step-by-step technical guides for SSH access, submitting jobs, managing
software environments, storage, and more are maintained separately at
**docs.vbc.ac.at**, the Vienna BioCenter's documentation portal. Keeping
procedural content there, rather than duplicating it here, means you always
read the current instructions rather than a copy that can drift out of date.

## CBE documentation

Start with the [CBE overview](https://docs.vbc.ac.at/research-computing/cbe/),
or go straight to a common task:

- [Run your first job with the CBE quick start](https://docs.vbc.ac.at/research-computing/cbe/quick-start/)
- [Connect with SSH](https://docs.vbc.ac.at/research-computing/cbe/ssh-system-access/)
- [Use OpenOnDemand web applications](https://docs.vbc.ac.at/research-computing/cbe/openondemand-web-applications/)
- [Submit and manage SLURM jobs](https://docs.vbc.ac.at/research-computing/cbe/slurm-jobs/)
- [Submit GPU jobs](https://docs.vbc.ac.at/research-computing/cbe/gpu-jobs/)
- [Find and load software with EESSI](https://docs.vbc.ac.at/research-computing/cbe/software-environment-eessi/)
- [Choose storage and transfer data](https://docs.vbc.ac.at/research-computing/cbe/storage-and-data/)
- [Troubleshoot problems and get support](https://docs.vbc.ac.at/research-computing/cbe/troubleshooting-and-support/)
- [Read the documentation change notes](https://docs.vbc.ac.at/research-computing/cbe/change-notes/)
